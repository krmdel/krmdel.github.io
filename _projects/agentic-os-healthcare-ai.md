## Description

<p style="text-align: justify; line-height: 1.6;">
Architecting and developing a production-grade Agentic OS for automated medical reasoning and assisting physicians on decision-making as a full-stack platform towards medical superintelligence. The system uses RAG on relational data (PostgreSQL + Vector DBs), short- and long-term memory, and a modular skills/plugins layer with MCP; unit, integration, and E2E tests are in progress alongside CI/CD for reliable, repeatable deployments across on-prem and cloud environments.
</p>

<p style="text-align: justify; line-height: 1.6;">
Currently improving domain-specific medical reasoning via distributed multi-GPU post-training of open-source LLMs on clinical datasets, with the fine-tuned model integrated into the Agentic OS to enable automated “AI doctor” workflows. Monitoring, evaluation, and dashboards for model and system performance are also underway.
</p>
